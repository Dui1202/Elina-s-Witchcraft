# 🧙‍♀️ Elina's Witchcraft - Wave Survival Game

Welcome to **Elina's Witchcraft** — a fast-paced wave-based survival game where you play as a powerful witch defending against an endless horde of monsters! Use magic projectiles, upgrade your spells, and survive for as long as possible! 💥

---

## 🎯 **Game Objective**
- Defend yourself against waves of enemies.
- Choose the right projectile to counter enemy types.
- Survive as long as possible without letting any enemies pass through!

---

## 🎮 **How to Play**
- **W / S:** Move Up / Down ⬆️⬇️
- **J / K / L:** Switch between Fireball, Snowball, and Windstorm 🔥❄️💨
- **SPACE:** Shoot your current projectile 🎯
- **Don't let any monsters pass!** If they cross the boundary, it's Game Over! ⚔️
